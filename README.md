
# Мой первый проект: Крестики-нолики на Python

Это моя первая игра, которую я написала в рамках обучения. 
В основе лежат классы и методы (ООП).

# Что умеет игра:
- Очищает экран в консоли для удобства (через модуль os).
- Проверяет, занята ли клетка перед ходом.
- Сама находит победителя или объявляет ничью.

Запускается просто через `python game.py`. Буду её дорабатывать!
